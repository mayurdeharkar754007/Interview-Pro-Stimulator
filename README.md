# InterviewPro Simulator 🚀

An interactive technical interview simulator designed to help developers prepare for coding interviews with real-time scoring, feedback, and performance analysis.

## ✨ Features

- **Interactive Challenges**: Practice real-world interview questions in a timed environment.
- **Real-time Scoring & Feedback**: Get instant feedback on your answers.
- **Performance Analysis**: Detailed breakdown of your performance to identify areas for improvement.
- **Modern UI**: Sleek, responsive design with beautiful micro-animations and themes.
- **Progressive Web App (PWA)**: Installable on your device for quick access.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Custom styles, CSS variables, and modern layouts (Flexbox/Grid).
- **Vanilla JavaScript**: Core logic, state management, and interactivity without heavy frameworks.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mayurdeharkar754007/Interview-Pro-Stimulator.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Interview-Pro-Stimulator
   ```
3. Open `landing.html` or `index.html` in any modern web browser.
4. Start practicing!

## 📂 Project Structure

- `index.html` & `landing.html`: Main application views.
- `styles/`: Contains stylesheets including the core design system.
- `app.js`, `questions.js`, `js/landing.js`: JavaScript files containing application logic and the question bank.
- `manifest.json` & `sw.js`: PWA configuration for offline capabilities.
